# v6 manual-guide baseline

These are the original v6 generator, player and packing sources, retained for comparison. The twenty open movements and their visit order are image-specific in `global_plan.py`; this is not an automatic portrait planner.

The historical scripts expect their original source/reference and output directories. Use the root v7 CLI for new input. Large generated HTML files, reference artwork and per-stroke JSON are not committed; the generation logic is complete here.
