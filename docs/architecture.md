# v7.0 人物自动规划方案

当前方案将 v6 的人工构图走势替换为图像结构分析，保留可逐笔核查的几何、取色与共享画布。它是人物生成的第一条自动基线，不是已完成的人体理解模型。

## 输入到画谱

| 环节 | 当前实现 | 边界 |
| --- | --- | --- |
| 图像预处理 | EXIF 方向、白底合成透明图、等比例归一分辨率 | 输入分辨率与工作分辨率分别记录 |
| 开放走势 | 低频 Lab 聚类、连通支持场、PCA／平滑骨架主轴、局部厚度估计笔宽 | 分组只供分析，不裁切落笔 |
| 访问顺序 | 大视觉质量与邻近端点共同排序，可反转走势方向 | 当前不理解人体部位或遮挡 |
| 铺形与明暗 | 整体低频铺色，沿开放轴成组塑形，检查主面与转折代理指标 | 代理指标不等同于人能认出形体 |
| 体积与细节 | 方向场、结构张量和画布残差选择笔触 | 误差收益不能单独决定自然笔序 |
| 时间轴 | 串行笔迹、起止时间与抬笔间隔 | 对数时间映射不改变画谱 |

`auto_guides.py` 提取走势；`build_portrait.py` 调用它并生成四阶段画谱；`construction_episodes.py` 完成一段走势的塑形与检查；`global_plan.py` 组织注意路线和时间轴。`player_v7.html` 回放，`playback_clock.js` 定义时间映射；`tools/render_player.py` 打包指定画谱与完整生成代码，`tools/export_svg.py` 导出静态矢量帧。`pack_v7.py` 保留单文件完整代码组合逻辑，生成的重复源码不提交。

OpenCV 内置 Haar 正脸检测仅提供可选注意焦点。它是预训练分类器，不产生人体姿态、肢体关系、衣物走势或前后遮挡信息。

## 已知反馈断口

`construction_sequence()` 对 `needsRevisit` 仅追加一次有限补画；补画后仍未完成也会转移。这保留了真实状态，却尚未保证“先建立可辨认主面再离开”。

下一步先让这一反馈进入调度：分清主面不连通、转折不足和无改善，再调整笔宽／方向／用色。达到可辨认代理或明确记录无法改善后才转移。不能用无限补笔、细笔填像素或增加重试次数掩盖错误走势。

在这项闭环验收后，再决定是否加入自动姿态／脸部关键点提示；提示应与开放色面轴共同使用，低置信回退必须可见，不转为封闭部位遮罩。

## 渲染与导出

每笔保存中心路径、左右边界、颜色、透明度和时序。当前生长几何只截取已走过的中心路径及相应边界，避免宽遮罩提前露出远端。已完成笔迹在播放器中用 Canvas2D `Path2D` 缓存相同 SVG 路径；当前一笔是 SVG。导出以画谱为依据，不以播放器截图或原图蒙版替代矢量内容。

对数展示时间为 `t = T·ln(1+99s/D)/ln(100)`，反函数用于播放推进。前慢后快；保留原始时间供逐笔检查。图示或过程预览若使用压缩时间，需标明同一映射。

## 验收

固定多张人物样例和相同参数，保存自动走势、前期固定笔数画面、连续原速片段、阶段结果和最终对照。分别报告形体可辨性、转移原因、取色／几何／时序正确性及最终相似度。现有三张样例完成自动跑通，用户本机图库验证仍未执行。
