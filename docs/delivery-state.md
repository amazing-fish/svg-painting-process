## 根因与修复

1. 旧版样例3前73笔是网格 `base_wash`，长宽比固定1.317，笔宽约最长边13.735%；原生1448仍有66笔同型粗块。v6没有此段。已删除，让第一笔直接跟随开放走势；合成曲线回归先红1.317、修复后绿，真实落笔保留曲率。
2. 仅删网格仍是巨宽灰团。当前把低填充、低实体度多肢支持场按PCA当作单面；局部分支实验虽降低部分缺口，仍未复原腿部与顺序，拒绝发布该未达标提轴改动。现有自动轴能力限制保留。
3. `Unexpected token '_' / __PAINTING_DATA__` 来源是误开根目录源码模板。现在模板给出明确说明和产物链接；统一打包严格检查指定script容器，缺失/重复/错误占位拒绝；合法源码中的占位例子不误替换。
4. 用户本轮明确要求上传HTML，覆盖了之前“生成物仅本地”的默认范围。只上传选定HTML/其内嵌预览、SVG静帧/测量、源码ZIP，原图库不整库上传；不自动部署Pages。
