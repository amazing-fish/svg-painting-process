# 开放主面实验：初始载色与白隙保护

2026-10-27，Asia/Shanghai。此入口用于重放和验证已经生成的开放走势，不替代默认的自动提轴，不表示人物效果已通过验收。

## 这次解决的具体问题

原参考图的两头部走势实验在第41笔停止。真实画布逐笔重放显示，前27笔和前头5笔没有造成后上发的主要白漏；后上发第1笔（全局第33笔）把 `whiteLeakP95` 从0.000027推到0.435534。总主面能量仍从0.945532下降到0.299693，因此旧候选排序接受了这一笔。后续有限补画无法恢复，最终白漏仍为0.175253。

热点位于飞发、浅色材质与空隙混杂处，不能将所有近白像素都认作外部背景。当前指标是源相对的局部占据测量，不能替代语义分割或人物效果验收。

原初始宽铺阶段关闭了已有的载色拟合。同样三个开放路径模板，直接宽铺的白漏都超过0.12；启用既有拟合后，其中两个仍为完整宽笔，白漏为0.003741和0.005425。拟合通过改变整笔路径区间与压力来保持连续载色，不裁切笔触内的像素。

## 接受策略

只在带有 `model-attention` 几何契约的阶段0初始主面候选上应用：

1. 按原方式生成整笔并在当前画布预演。安全的原候选保持原样。
2. 若预演白漏超过 `max(0.12, 当前画布白漏)`，尝试同一模板已有的载色拟合。
3. 拟合候选仍必须通过完整物理几何、像素收益、白漏和主面能量收益检查；缺少候选或仍不安全则整笔拒绝。
4. 每次以当前画布重新判断，不缓存安全结论，不扩大绘画预算，不将低置信度或无法改善标成完成。

0.12沿用已有的白漏就绪上限。**将该上限用于逐候选保护属于接受语义变化**，并非“规则完全不变”；主面就绪阈值、候选模板参数及14笔初始/5笔补画预算保持不变。当前实验没有对后续所有绘画阶段作同等保证。

对于有独立源图支持证明的 `geometryReady` 输入，插值、载色偏移和收尖后的最终笔带必须用其实际法向再次测量源图。原有站点合格不代表站点之间或偏移后的宽度合格；最终检查失败则整笔拒绝。独立审查的合成回归证实，三个有效源支持点之间仍可能连接出跨越空白的笔带；此漏洞已用最终几何重测修正。`model-attention` 输入继续标记 `sourceReady=false`，不能借此获得独立源轮廓证明。

原图1086×1448，输入17条自动开放轴，源图和输入SHA冻结。v6手工走势只作外部评价，不进入生成输入。

| 实验 | 结果 | 判断 |
| --- | --- | --- |
| 原两头部实验 | 41笔，后上发未就绪 | 失败基线 |
| 所有初始头部笔都强制载色拟合 | 36笔，前头补画预算耗尽；E=0.080359 | 拒绝采用；削弱原有效主面 |

最终64笔运行中，前32笔的完整字典与41笔基线逐值相同，前58笔与65笔中间结果相同。后上发仍使用8笔初始加1笔补画，终值为 E=0.076380、P90=0.154344、白漏=0.104499，所有已接受头部笔的白漏保持在原0.12上限内。末尾第16号走势（从0计）初始2笔加补画5笔后 E=0.170687、P90=0.272162，预算耗尽，阶段0 `complete=false`，未进入明暗阶段。该轴7条实际笔迹的最终源支持检查均通过；另4种源几何候选被整笔拒绝。

64笔不是已完成人物：头面仍宽、脸向与发流未通过人工效果验收，部分衣物/飘带结构仍不成立。更多笔数和局部ready不代表整体更自然。原100/140/185/210笔定位仍不可用。

## 显式重放入口

安装根目录 `requirements.txt` 后，在仓库根目录运行：

```text
python -m experiments.portrait_coarse --source <image.png> --guides <guides.json> --provenance <provenance.json> --output <new-output-directory> --through 2
```

图像、开放走势和来源绑定必须由调用方显式提供。输入格式和校验要求见 [实验包说明](../experiments/portrait_coarse/README.md)。入口不联网、不启动姿态模型，也不自动寻找本机缓存。`--through 2` 请求前两阶段，但粗层未就绪就停止；此时退出码1代表如实记录了未完成，退出码2代表输入或执行错误。

输出保存实际逐笔数据、阶段SVG、末帧PNG、候选选择记录和停止原因。`painting-data.json` 的播放器兼容版本为7.2，独立的 `experiment.version` 标记为 `portrait-coarse-v8.1`，不能因此将实验结果误认作正式v7.2生成结果。

第一次模块化重跑曾精确复现65笔中间结果（52.172秒）。独立审查修复后再次实跑得到上述64笔，不能将旧65笔播放与耗时冒充最终代码结果。最终画谱、末帧及回放保留本地；帧率和多人/多图效果未验收。
