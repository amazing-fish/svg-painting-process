本机样例覆盖头像、半身、坐姿全身复杂服饰、双人和动态人物；照片人物和中性站姿全身仍缺样。清单固定后不逐图调坐标、笔序或参数，自然度仍待人工观看判断。

当前实现可以明确阻塞或停滞，不能保证所有形体已可辨认。下一判断应来自相同样例、参数和原始时间的失败证据：开放走势错误、笔宽／方向错误与停止条件错误分别核对，再决定人物开放结构提示是否有必要。不扩展风景，也不重新展开泛化调研。

本轮提交聚焦 PR、审查结果与简明 HTML 人工报告，不自动合并。GitHub Pages 是后续发布需求，本轮不部署；发布前审查拟公开 HTML 的内嵌内容。图库与大生成物继续留本地。
